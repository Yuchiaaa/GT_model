# GT_model
This is a homework for our course Simulation and Modelling. It obtains a 1D cellular automata which is used for showing the n-P Prisoners' Dilemma across times..
Included are the main program, which is gt.py. There is also the notebook gt.ipynb, which generates different plots to show the results. As a sort of 'side project,
there is also the sim_1v1.py, which was the first failed attempt at the assignment, but is included because in the end we did use it for some small extra experiments.
